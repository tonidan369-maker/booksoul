# BookSoul Store Screenshots

يستفيد هذا المسار من مشروع [`ParthJadhav/app-store-screenshots`](https://github.com/ParthJadhav/app-store-screenshots) لإنشاء أصول App Store وGoogle Play القابلة للتكرار. المشروع مرخص MIT ويعمل كمحرر Next.js مستقل؛ لذلك يحتفظ به منفصلًا عن Flutter runtime.

## خطة الشرائح العربية

| الشريحة | الوعد التسويقي | لقطة المصدر المقترحة |
|---|---|---|
| 1 | مكتبتك العربية الهادئة | الصفحة الرئيسية الجديدة للمكتبة |
| 2 | اكتشف كتابك القادم | البحث والوسوم وبطاقات الكتب |
| 3 | اقرأ بطريقتك | القارئ مع السمات وحجم الخط |
| 4 | احتفظ بما يهمك | الملاحظات والعلامات المرجعية |
| 5 | تابع رحلتك | التقدم والملف الشخصي |

## التشغيل المقترح

بعد التقاط لقطات فعلية من محاكي Android أو جهاز فعلي، أنشئ محررًا مستقلاً عبر:

```bash
npx skills add ParthJadhav/app-store-screenshots
```

بعد ذلك شغّل المحرر، أضف اللقطات ومحتوى الشرائح أعلاه، وصدّر حزمة PNGs بالمقاسات المطلوبة. يجب حفظ `app-store-screenshots.json` واللقطات النهائية داخل Git حتى تبقى الأصول قابلة لإعادة الإنتاج.

> لا تضف أي بيانات مستخدم حقيقية أو مفاتيح أو شاشات تحوي معلومات حساسة إلى أصول المتجر.
